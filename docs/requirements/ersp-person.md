# Физическое лицо в запросах ЕРСП: требования

Записано по сообщению Бекзода 22.10.2026 (скопировано из Swagger, подробно
не разбиралось). Это требования, а не модель: модель — `docs/counterparties-model.md`,
раздел «Физическое лицо». Данных конкретных людей здесь нет — только поля.

В договоре `person` (`CreateOtherContractV3Person`, «информация о физ. лице
страхователе») отправляются страхователь, выгодоприобретатель, застрахованный,
владелец объекта и другие участники. Те же поля — у `agency[person]` агента
(`docs/requirements/ersp-agencies.md`), кроме отдельных, отмеченных ниже.

| Поле | Что | Правило ЕРСП |
|---|---|---|
| `regionId` * | регион, справочник `/api/references/regions` | у иностранца (`residentType` = 2) необязателен |
| `gender` * | пол: `m` — мужчина, `f` — женщина | (у `agency[person]` поля нет) |
| `birthDate` * | дата рождения | |
| `address` * | адрес | |
| `residentType` * | справочник `/api/references/resident-types` | если указан ПИНФЛ, не может быть 2 (иностранец) |
| `countryId` * | страна, справочник `/api/references/countries` | |
| `phone` | `998ххххххххх` | необязателен только у иностранца |
| `email` | эл. почта | обязательна только у иностранца |
| `driverLicenseSeria`, `driverLicenseNumber` | водительское удостоверение | необязательны |
| `passportData[pinfl]` | ПИНФЛ | если не гражданин РУз — необязателен |
| `passportData[seria]` *, `[number]` * | серия и номер паспорта | |
| `passportData[issuedBy]`, `[issueDate]` | кем и когда выдан | необязательны |
| `fullName[firstname]` *, `[lastname]` *, `[middlename]` * | ФИО | при отсутствии отчества — «ХХХ» |
